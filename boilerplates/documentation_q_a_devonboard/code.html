QUERY MATCH How do I seed user accounts in the local PostgreSQL database?
100% confidence | Matched in 8ms
Verified Solution Source: README.md:14 & config/database.ts

The PostgreSQL local container automatically provisions schemas on first spin-up. To populate required seed personas and credentials, run the Prisma migration sequence followed by the idempotent mock data seeder.

This script provisions administrative rights, engineer sandboxes, and read-only test roles. Do not run db:seed:mock in production or staging environments as it injects predefined JWT bypass keys.

bash terminal
target: local-docker
$ pnpm db:migrate && pnpm db:seed:mock

Resolving port 5432 conflicts on macOS

If Docker reports bind: address already in use, native Homebrew PostgreSQL service is likely claiming port 5432 in the background. Stop the native daemon or kill the lingering socket process.

homebrew service manager
$ brew services stop postgresql && brew services stop postgresql@14
Alternative: change POSTGRES_PORT=5433 inside your .env.local override file. Verified fix
